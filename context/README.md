# context/

Lightweight, hand-maintained context files to help pick up work quickly across sessions.

- **`_active.md`** — what feature/branch is currently being worked on, and where to find its
  spec/plan. Update this whenever you switch focus to a different feature.
- **`_project.md`** — high-level map of the project: stack, key directories, conventions,
  testing setup, and config notes. Update when the architecture or conventions change.
- Other files in this directory (if added) are per-feature context files referenced from
  `_active.md`.
